ℹ️ 關於本站

CBOT Physics Simulations 係一個專為中學物理教學設計嘅互動模擬平台，
所有模擬都可以喺瀏覽器直接運行，毋須安裝任何軟件。

🎯 設計目的

物理概念（尤其係聲波同波動）往往比較抽象，學生難以憑空想像。透過互動模擬，學生可以即時調整參數（頻率、振幅、波長等），觀察波形變化，加深理解。

💻 技術架構

  • 純 HTML + CSS + JavaScript，毋須後端伺服器
  • 使用 Web Audio API 同 Canvas 進行即時繪圖
  • 響應式設計，支援桌面同平板
  • 託管於 GitHub Pages，免費且穩定

🚀 使用說明

  • 進入模擬頁面後，用 slider 或輸入框調整參數
  • 部分模擬支援 Oscillator / Microphone 切換
  • 如果見唔到最新版本，請按 ⌘+Shift+R (Mac) 或 Ctrl+F5 (Windows) 強制刷新
